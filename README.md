<h1 align="center">SHAKES AND FIDGET OVERLAY</h1>
<p align="center">Your aid to keep track of your in-game timers</p>
<p align="center">Supports multiple characters</p>


<p>The script fetchs your current in-game timers and keeps track of the time left, use alt+u to update the timers after you have logged and did your tasks.</p>

## Installation
```bash
git clone https://github.com/Momin-Ahmed-Mebarez/sf_overlay.git
cd sf_overlay
pip install -r requirements.txt
```

## Usage
Please check [IMPORTANT-NOTE](#IMPORTANT-NOTE) before running the script.
```bash
python src/__main__.py
```
## Shortcuts
alt+s hide/unhide the overlay<br>
alt+x Exits the overlay<br>
alt+u Updates the current character <br>
alt+c Changes the current displayed character (The first call will be slow as it sends a request to the servers)

## IMPORTANT-NOTE
<p><b>I have contacted SF support and they told me they can't guarantee that the script won't cause accounts to get banned. Use at your own risk.</b></p>
<p><b>I have added a 5s cooldown for switching characters (For the first time you fetch character data) and updating it's information this is to reduce spam but even though I recommend not spamming every 5s</b></p>
